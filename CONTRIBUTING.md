# Submission Guidelines

This repository follows the official **Bob AI Hackathon Submission Template**.

## Rules
1. Do not modify `.github/workflows/validate.yml`.
2. Ensure `submission.yaml` is filled completely before final submission.
3. Keep all source code in `src/`.
4. Ensure all branches follow the team workflow guide in `TEAM_WORKFLOW_AND_GIT_GUIDE.md`.
